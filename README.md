# Linear-Regression-Project
Welcome to my Linear Regression Project! This project is the start of a series of ML projects, where I investigate the fundamentals that power modern AI systems today. 
- Find my model inside the "Linear Regression Demo.ipynb" Jupyter Notebook: To get the model working, see the "Requirements" section within my notebook for more details on how to configure my model and install the appropriate kernels needed to run the notebook on your server.
- Find sample training datasets inside the "Datasets" folder: these could be in the form of any text file (e.g. .csv, .txt or .data), but ensure that the dataset is tabular in design with exactly one column designated as a target.
- Find sample visualisations inside the "Resources" folder: these include gifs showcasing how the model learns the line of best fit depending on the learning rate and the number of epochs.

Feel free to clone this repository or download all the files to play around and investigate my linear regression model. All enquiries and questions are welcome. Thank you!
